# ИМПЕРИЯ АВТО — сайт автосалона (VOYAH · LI AUTO)

Премиальный лендинг дилерского центра с интерактивным 3D-шоурумом на WebGL.

## Как открыть
Двойной клик по `index.html` — сайт полностью автономен (шрифты и three.js лежат
в проекте, внешних запросов нет). Либо любой статический хостинг: Netlify Drop,
GitHub Pages, Vercel — просто загрузить папку.

## Что внутри
- **Интерактивная 3D-сцена** (three.js r150, процедурная геометрия):
  VOYAH FREE → LI AUTO L9 → VOYAH ZHUIGUANG → VOYAH DREAM.
- **Мышь меняет ракурс** автомобиля (плавный демпфированный облёт камеры;
  при простое — мягкий авто-дрейф).
- **Скролл = конвейер**: текущий автомобиль уезжает (носом вперёд, вращение
  колёс, конусы света фар, полосы скорости), следующий въезжает и «припадает»
  на подвеске. Камера с каждым актом обходит сцену по кругу, как в шоу-руме.
- **Секция «кино-осмотр»** — тот самый приём «видео, нарезанное на микро-кадры»:
  120 кадров из ролика, прокрутка колеса листает кадры на полноэкранном canvas
  (загрузчик кадров, полоса прогресса, параллакс от мыши). Сейчас — стоковый
  клип (демо техники); заменить на генерацию GPTunnel одной командой ниже.
- **Зеркальный пол**, поворотный стол со световым кольцом, студийный свет
  (softbox-окружение запечено в PMREM), туман, киношное зерно и виньетка.
- **Смена цвета кузова** — свотчи в карточках каждой модели (плавный перелив).
- Бизнес-блоки: преимущества (bento), цифры со счётчиками, форма записи на
  тест-драйв (валидация + success-состояние), футер с контактами.
- Прелоадер со счётчиком, кастомный курсор, магнитные кнопки, рельс прогресса
  моделей, бегущая строка.

## Пайплайн «настоящий Voyah в кино-осмотре» (GPTunnel)
1. Положите ключ в `tools/api-key.txt` (или env `GPTUNNEL_API_KEY`).
2. Возьмите фото реального авто (от дилера) и запустите image-to-video:
   `node tools/generate.mjs video --model kling-v3 --first-frame photo.jpg --prompt "камера медленно облетает автомобиль по кругу, тёмный шоурум" --dur 5 --out media/src/voyah.mp4`
3. Нарежьте: `node tools/slice.mjs media/src/voyah.mp4 120 1600 media/cinema`
4. Готово — секция сама подхватит новые кадры.
   Список моделей: `node tools/generate.mjs models`. Справочник: docs.gptunnel.ru

## Технические детали
- Никакой сборки: чистые HTML/CSS/JS. Классические скрипты — работает с file://.
- Акцентный цвет интерфейса и сцены меняется по актам: медь → лёд → красный → индиго.
- `prefers-reduced-motion`: отключаются полосы скорости, приседание подвески,
  авто-дрейф камеры; вся анимация — на rAF + таймерный watchdog для webview.
- Тест-хук `?jump=N` — мгновенный переход к позиции скролла (проверка актов).
- Доступность: семантические секции, aria, focus-visible, контраст текста
  поверх сцены через тень.

## Кастомизация под клиента
- Цены, характеристики, тексты — прямо в `index.html` (секции `.act`).
- Цвета кузовов и акценты актов — в `js/scene.js` (массив `SPECS`).
- Телефон/адрес — шапка и футер (`index.html`).
- Форма: отправка сейчас локальная (success-состояние). Для интеграции
  замените обработчик `submit` в `js/app.js` на fetch к вашему CRM/API.

## Примечание про изображения
Автомобили — стилизованная процедурная 3D-визуализация (дискclaimer уже в
футере). Для «живых» фото/видео реальных машин можно подключить генеративные
API (GPTunnel и т.п.) — потребуется API-ключ; интерактивный ракурс от мыши
при этом останется только на 3D-сцене, видео на такое не способно.
